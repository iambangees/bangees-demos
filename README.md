# Bangees — Client Demo Sites

Free one-page demo websites built for real prospect businesses, per the freelance
playbook in `~/workspace/freelance-offer/FREELANCE_OFFER.md`. Each demo uses only
facts verified about the business (name, dishes, address, hours, public phone /
Instagram) — **no invented prices or details**. Every demo carries a note saying
it is a free sample by Bangees, linking to the services page.

- `site/sekem-sky/` — Sekem Sky (Lekki) — WhatsApp order buttons use its real lines.
- `site/oriri/` — Oriri (Ikeja) — no verified phone, so the CTA is its Instagram.
- `site/amala-tohsure/` — Amala Tohsure (Akoka) — WhatsApp/call order buttons.

Live under `https://iambangees.github.io/bangees-demos/<slug>/` once published.
Prospect tracking lives in `~/workspace/freelance-offer/TARGETS_RESTAURANTS_LAGOS.md`.
